AI setup (MCP)

      
Let an AI agent configure the pad: register this app's MCP server with your tools. Tools: list_keys, get_key, set_key, sync_pad, press_key, list_runs, list_macros, set_macro, delete_macro, and show_pad, which shows the pad as an interactive view right in the chat (MCP Apps: Claude, ChatGPT, VS Code and other hosts that support it).

      
The MCP server is not available in this build.
